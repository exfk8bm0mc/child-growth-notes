# 【科学育儿】新生儿护理小常识，准爸准妈们注意收藏啦！

> 更新时间：2026-09-17 (UTC+8)

刚出生的宝宝正经历从子宫内到独立生活的巨大变化,TA的消化、呼吸、体温调节能力均较差，抵抗力低，容易感染。那宝爸宝妈们该如何喂养和护理呢？

**1.宝宝的正常体温是多少？**
　　刚出生时，由于环境的变化，体温很快下降,12～24小时内经体温调节逐渐上升到36度以上。可是，因为发育未完善，皮下脂肪较薄，体表面积大，容易散热，所以体温常波动不稳，有时体温可达到37度以上，甚至超过37.5度。妈妈们要注意宝宝体温的变化，适时的增减包被，防止低体温引起的硬肿症和过热造成的热脱水。

**2.怎样给宝宝测体温？**
　　常用有三种部位，即肛门、皮肤、腋下。肛门和皮肤两个部位的温度测量现在已经很少使用，常用的是腋下部位。腋温的优点是对宝宝干扰少，受外界影响小，兼有肛温和体温的优点。常用的水银柱玻璃体温计较准确。

**3.宝宝室内的适宜温度、湿度应是多少？**
　　刚出生的宝宝居室的温度应保持在22～24度，湿度应保持在60％～65％左右。室温过低所致的体温不升，可影响宝宝代谢和血液循环，若过高可引起发热。适当湿度使人感到皮肤干爽舒适，呼吸顺畅不干涩，并且不利于灰尘漂浮。所以适宜的室温对宝宝很重要。

**4.怎样给宝宝保暖？　**
　　宝宝的体温调节功能不健全，受环境影响体温会出现过冷或过热现象。不注意护理，容易出现问题。一般可以摸宝宝的面额、手心等部位，以温热无汗为合适。如果宝宝四肢发凉，皮肤出现紫花纹，要立即加热水袋保暖（水温应在50度左右）。

**5.早产的宝宝需要注意哪些问题？　**
　　胎龄不足37周，提前降生到世间的宝宝，各器官生理功能均不成熟，如果护理不当，很容易出现问题。

　　注意呼吸，早产的宝宝呼吸不规则，常出现停止现象，如果停止时间超过20秒以上，伴有紫绀的要及时给与氧气吸入等处理措施，防止呼吸衰竭。

　　注意体温，早产的宝宝散热大于产热，体温常偏低不升，一定要注意保暖，防止发生硬肿症。但是早产的宝宝出汗功能差，保暖过当同样也可造成危害，出现高热甚至抽风。

**6.怎样知道宝宝的衣服、包被是否合适？**
　　给宝宝穿衣、包被很有科学，包裹太多太少都会影响宝宝的健康。包的过多过厚，宝宝长时间浸泡在汗水中，这种不舒服的感觉能影响睡眠，还容易伤风感冒，久之体质虚弱多病。而包被的少同样也会产生不良后果。怎样恰到好处的护理呢？给宝宝穿衣、包被要根据天气、室内温度、宝宝体质状况、衣被的厚薄来适当处理。包被合适，宝宝能香甜、安静的长时间睡眠，手心脚心温热，很少感冒流鼻涕。　

**7.宝宝每天的尿量多少算正常？**
　　出生第一天尿量很少，大约10～30毫升，随着哺乳次数和量的增加，尿量每天可达100～300毫升，满月时可以达到450毫升。只要奶水量充足，尿呈清淡透亮，尿布上无明显沉淀痕迹也无黄染，无明显的尿骚味，就属正常。

**8.宝宝一天大便几次算正常？**
　　大便的性状、次数常因不同的饮食而异。牛奶喂养的宝宝，大便多呈淡黄色或灰土色，并且常有便秘倾向。而吃母奶的宝宝，大便多是金黄色的粘糊状，每天1～4次，也有4～5次，甚至每次换尿布都有大便排出。只要大便的性状不改变，宝宝的身长体重正常增长，精神好，妈妈就不必惊慌，这是母乳喂养的正常现象。

**9.新生儿洗澡应注意哪些问题？**
　　新生儿每天要洗澡。会阴和臀部应保持清洁。洗澡前要将室温提高到23度～26度，水温一般在37～38度为宜。

　　( 1 ）将宝宝仰放在澡盆里，用手托住他的头，用左手的拇指和中指从耳朵后面向前推压耳廓，堵盖住耳朵眼，防止水进入。

　　( 2 ）先洗头面部，依次是躯干、四肢、手脚等。脐带未脱落的要绕开不洗。

　　( 3 ）宜用无刺激性的洗涤用品，动作要快，每次不宜超过10分钟。

( 4 ）浴后用软毛巾吸干，不宜揩擦。

( 5 ）衣服应柔软，宽适，天天换洗。

**10.新生儿脐带如何护理？**
　　( 1 ）脐带一般 1～7 天脱落。

　　( 2 ）脐带未脱落前给宝宝洗澡时不要弄湿，可每天用75％酒精棉棒擦洗其根部及周围皮肤1～2次，预防感染。

　　( 3 ）当脐带脱落后发现有渗出液时，除了要进行局部消毒，一定要保持千燥，不要包扎或覆盖脐部。

　　( 4 ）如伴体温高时，要加用抗生素消炎，防止炎症的进一步发展。有时脐部会有小的增生的肉芽组织，可以到医院进行处理。

**11.新生儿生理性黄疸什么时候消退？**
　　宝宝出生24小时后，皮肤粘膜逐渐出现肉眼可见的黄染（全身皮肤、手心脚心、眼结膜等），这就是人们常说的新生儿黄疸。新生儿黄疸分生理性黄疸和母乳性黄疸。

　　（１）生理性黄疸大都在生后2～3天出现，１周左右开始消退，10 ～14天完全消退，早产儿可以持续到3～4周才消退。

　　( 2 ）母乳性黄疸虽然持续的时间长，可达1～2 个月，但是，宝宝一般情况良好，精神发育及食欲无异常，安静无烦躁。

　　( 3 ）病理性黄疸最早可以发生在生后24小时内，或晚到5天后，黄疸进行性加重，重者全身黄染，色泽由橙黄转为金黄。

　　导致异常黄疸的原因有：溶血性疾病、感染败血症、肝炎、先天性胆道闭锁等多种疾病。宝宝多伴有其他方面的异常，如，嗜睡、烦躁、惊厥、呕吐、发烧等异常症状，出现这些症状，需要及时到医院诊治。

**12.新生儿屁股红了怎么办？**
　　( 1 ）尿布包裹不要过紧；

　　( 2 ）尿布要勤换；

　　( 3 ）屁股要经常保持清洁干爽；

　　( 4 ）用清水清洗屁股，不要使用洗涤剂以防过敏；

　　( 5 ）每次洗完屁股后，让新生儿趴着对着阳光晾干，日光对红臀有消毒和预防的作用； 　

　　( 6 ）严重的红臀可以适当擦涂外用消炎软膏，千万不要使用粉剂涂擦，否则会加重症状。

**13.鼻涕痂堵住宝宝的鼻子怎么办？**
　　新生儿鼻塞时不会张口呼吸，鼻塞可引起呼吸困难。新生儿应保持鼻孔通畅，如有鼻涕痂，可用温开水浸湿的棉棒轻轻取出。

**14.宝宝能用枕头吗？**
　　月子里的宝宝一般不用枕头。待满月后宝宝的脊柱逐渐伸长，根据脊柱的生理弯曲的形成可以选择使用枕头。枕头的长度应与肩宽相等或稍宽些，宽度略比头长一点，高度约5厘米，枕头用棉布制做，枕心柔软透气，最好选用荞麦皮，否则宝宝颅骨容易变形。

　　亲爱的粑粑麻麻们，了解宝宝的特点，做好喂养和护理，是保证宝宝健康的关键哦！
